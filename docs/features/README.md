# 功能实现文档目录

本目录按开发顺序保存每个功能的详细设计和手写指南。开始新功能时先复制下面的结构，并使用三位编号命名文件。

## 当前功能文档

- `001-前后端聊天接口接入.md`：打通 Vue、FastAPI 与 Agent 的最小请求链路。
- `002-结构化日志与请求ID.md`：为服务端异常增加可关联的结构化诊断信息。
- `003-会话消息持久化与多轮对话.md`：使用 PostgreSQL 保存会话消息，并为 LangGraph 构造多轮上下文。
